§File format

  • A header block. The first rows of each CSV (and the Parquet metadata) give the source, licence, credit line, "as of" time and the method page's address.
  • A status column. Blank numbers come with a reason. A blank is never a 0.
  • Provisional rows. Results from states that have not certified are marked provisional, row by row.
  • The same numbers as the screen. A table's CSV export and its dataset here come from the same read.
  • A version in every file. The header block carries the version and its DOI, so a file found later can still be cited and checked against the changelog.
